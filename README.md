# Fotowetter-Planer

Grundgerüst für eine React-TypeScript-Anwendung zur Planung fotografischer
Aufnahmen anhand von Wetterdaten und Sonnenzeiten.

## Technologien

- React
- TypeScript
- Vite
- React Router

## Projektstruktur

- `src/komponenten/` - wiederverwendbare Komponenten
- `src/seiten/` - Seiten und Ansichten
- `src/hooks/` - Datenlade-Hooks
- `src/typen/` - TypeScript-Datenverträge
- `src/utils/` - Hilfsfunktionen

## Installation

```bash
npm install
npm run dev
```
